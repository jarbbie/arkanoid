# Arkanoid

A simple Arkanoid-style game built with Rust and [Macroquad](https://macroquad.rs/).

## Controls

- Press `Space` to start or replay.
- Use the `Left` and `Right` arrow keys to move the platform.

## Run

```bash
cargo run
```
